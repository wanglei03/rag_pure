# 星海大模型平台产品白皮书(示例)

## 1. 产品定位
星海大模型平台是面向政企客户的一站式大模型应用开发与运行平台,覆盖模型接入、知识库、智能体编排、效果评估与运维监控全链路。

## 2. 模型接入
平台内置三类模型:
- 自研星海系列模型:星海 Lite(7B,端侧)、星海 Pro(72B,云端)、星海 Coder(代码专用);
- 第三方模型:支持接入通义千问、DeepSeek、GLM 等主流开源与商用模型;
- 客户私有化模型:支持 vLLM、TGI 部署的客户自有模型通过标准 OpenAI 兼容接口接入。
模型路由策略支持按成本、时延、效果三维度自动调度。

## 3. 知识库(RAG)
知识库模块支持 PDF、Word、Excel、PPT、网页等 12 种格式接入。
解析管线包含:版式分析、表格还原、OCR 图片文字识别、语义切分。
检索支持向量检索、全文检索与混合检索,内置 BGE 系列 embedding 与 bge-reranker 重排模型。
答案生成支持引用溯源,每个结论自动标注来源段落。

## 4. 智能体(Agent)
智能体模块提供可视化编排画布与代码 SDK 两种开发方式。
内置工具:知识库检索、HTTP 请求、代码执行、数据库查询、RPA 流程。
支持多智能体协作、任务规划、人工确认节点(human-in-the-loop)。
智能体可通过 API、企业微信、钉钉、网页插件四种渠道发布。

## 5. 效果评估
平台内置 RAG 评估集管理与批量评测功能,指标涵盖检索命中率、答案忠实度、答案相关性。
支持按评估结果一键回归对比不同配置的 pipeline 版本。

## 6. 部署形态
支持公有云 SaaS、专属云、纯私有化三种交付形态。
私有化部署最低配置:8 核 CPU / 32GB 内存 / 1 张 24GB 显存 GPU。
平台按调用 token 数与知识库容量组合计费,私有化按年订阅。

## 7. 典型客户场景
政务热线问答、企业制度咨询、合同审查助手、运维知识助手、营销外呼脚本生成。
